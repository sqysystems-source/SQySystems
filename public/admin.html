Σύνδεση καταστήματος

Συνδέστε το δικό σας e-shop. Τα στοιχεία διαχειριστή θα ζητηθούν ξεχωριστά στο επόμενο βήμα.

Το HTTPS domain του Vercel backend του καταστήματος, χωρίς /api. Τα tenant tokens θα αποστέλλονται σε αυτό το domain.

Firebase Console → Project settings → Your apps → Web config. Μόνο τα έξι δημόσια πεδία JSON. Ποτέ service account, private key, Resend ή R2 secret.
